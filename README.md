# Insurance Premium Category Predictor

A Machine Learning-powered web application that predicts insurance premium categories based on user details such as age, BMI, income, smoking habits, city tier, and occupation.

Built using:

- FastAPI (Backend API)
- Streamlit (Frontend UI)
- Scikit-learn (ML Model)
- Pandas

---

## Features

- User-friendly Streamlit interface
- FastAPI backend for predictions
- Real-time premium category prediction
- Feature engineering using Pydantic computed fields
- BMI calculation
- Lifestyle risk analysis
- City tier classification

---

## Tech Stack

- Python
- FastAPI
- Streamlit
- Scikit-learn
- Pandas
- Pydantic
